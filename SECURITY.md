# Security boundary

Experimental software. Internal methods are not HTTP authorization.
Never expose them unauthenticated. Host authenticates and scopes every adapter.

Use one verified private owner dialog and exact dot room. Preserve existing
browser drafts. Wrong-room and unknown delivery stop processing.
Native replies are experimental and disabled by default.

A regex cannot guarantee secret detection: it can miss secrets and hold harmless
text. Do not send credentials through the mirror. Editing one side cannot
guarantee withdrawal of previously shared data from the other destination.

Keep protected journal storage outside Git. Never commit environment files,
logs, sessions, screenshots, keys or private transcripts. Do not put credentials
in URLs or process arguments; use the host's existing secret store.
Public bug reports must contain synthetic reproductions, never real secrets.
